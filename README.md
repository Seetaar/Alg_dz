Коммент к ДЗ по обходу деревьев:
В pre конкатенация списков копирует ключи поддеревьев на каждом уровне рекурсии. Поэтому печать AVL-дерева занимает Θ(N log N), хотя требуется O(N). Организуй обход так, чтобы каждый ключ добавлялся в результат один раз, без повторного копирования накопленных списков.
